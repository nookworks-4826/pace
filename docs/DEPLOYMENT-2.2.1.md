# Pace 2.2.1 公開について

2026年10月7日、本人の明示依頼によりGitHub Pagesへの公開を進めます。

- 実iPhoneの確認は未実施。使用禁止にはせず、実機確認資料に沿って普段使いで確認する方針です。
- 旧公開版2.1.1からの直接更新で架空金融記録を保持すること、オフラインで再起動・解除・入力・Excel作成できることを検証済み。
- 更新は同じURL・保存領域を維持し、端末データを消す操作や銀行への接続を行いません。
- 更新前の家計バックアップは推奨しますが、今回の公開作業の前提条件にはしません。更新前ソースとGitHub履歴は保持します。
- バックアップがなくてもデータを保持する更新設計ですが、端末故障やブラウザデータの削除などからの復旧は保証できません。
- 公開後はいつものPaceを開き、更新表示があれば入力を保存して閉じ、「更新する」を押してください。再インストールやブラウザデータ削除は不要です。

[使いながら確認する手順](Pace%202.2.x%20iPhone実機確認手順.md)。実装・検証報告の「本番未公開」は公開前の検証時点の記録です。
