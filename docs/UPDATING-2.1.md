# Pace 2.1.1への更新

2.0.0／2.1.0の記録・パスフレーズ・ロック・表示設定を引き継ぐ更新です。アプリや保存データの削除、再インストールは不要です。

## アプリを使う人

1. Paceを開き、「設定」をタップします。
2. 「アプリの更新」の「更新を確認」をタップします。
3. 「更新を適用」が出たらタップします。入力画面が開いている場合は先に閉じます。
4. 設定画面のバージョンが **2.1.1** になったことを確認します。

## 使う場所

| したいこと                         | 設定の項目         |
| ---------------------------------- | ------------------ |
| 残高登録・カード明細の取り込み     | 口座・カードの管理 |
| 毎日の通知時刻やカレンダー用の予定 | 通知とリマインダー |
| 給料日と、予算を何日から区切るか   | 給料日と予算の期間 |
| 情報の保存先・暗号化・バックアップ | プライバシー       |

有料の銀行自動連携は採用しません。「口座・カードの管理」から残高登録やカードCSVの取り込みを始められます。銀行のログイン情報をPaceへ入力する欄や、自動連携の契約手続きはありません。

通知で「カレンダーの予定」を選ぶと、予定ファイルが作成されます。開いたファイルをカレンダーへ追加すると、カレンダーの通知設定に従って通知されます。時刻の変更や通知の停止は、カレンダー側の既存予定も編集・削除してください。

## 公開を管理する人

更新用フォルダーの **中身** を、既存リポジトリのトップにアップロードします。フォルダー名自体はアップロードしません。`.github`、`src`、`docs`、`scripts`などの配置を維持し、`package.json`はトップに置きます。

アップロード後はGitHub Actionsの`Test and deploy Pace`が成功するまで待ちます。失敗した履歴を消しても公開は更新されません。成功後に上記アプリ内の更新を適用します。

開発者の検証は`npm run test`、`npm run build`、`npm run privacy:audit`、`npm run test:settings`です。設定画面のブラウザー検証は、一時プロファイルと架空データだけを使います。iPhone・Galaxy実機や実口座の自動取得はこの検証に含めません。
