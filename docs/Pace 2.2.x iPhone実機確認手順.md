# Pace 2.2.x iPhone実機確認手順

対象は2.2.1です。この作業では公開していません。公開後は、いつもの操作をしながら下の項目を確認できます。実iPhoneでの完全検証済みとはしていません。

最初は少額の記録で確認してください。気になる動作があれば同じ操作を繰り返さず、直前の記録と残高を確認します。パスフレーズや銀行のパスワードをチャットへ送る必要はありません。

## 使わなくなった口座

「お金 → 対象の口座 → 使わなくなった口座をアーカイブ」。新しい入力候補から外れますが、過去の記録と合計資産に含む残高は残ります。「アーカイブ済みの口座 → 再表示」で戻せます。残高確認の間隔は各口座で1・3・7・14・30日・OFF。OFFは確認の促しだけを止め、残高計算は続けます。

## 重大問題が起きた場合の復旧

1. 新しい入力と更新を止め、可能なら新版の暗号化バックアップを別名で保存する。保護画面の場合は「元の暗号化データを保存」で保護用ファイルを保存する。
2. 更新前の確認済みバックアップを消さない。新版のファイルと混ぜない。
3. 旧版コードの再配信だけではschema 4の端末DBは戻らない。旧版を試す必要があれば、既存データを残した別のブラウザ／端末で、旧版が読める更新前バックアップを使う。
4. 旧2.1.1へ戻すと、その版が理解しない機能や更新後の記録はそのまま戻らない可能性がある。通常はデータを維持する修正版への更新を優先する。
5. 保護用ファイルは通常のバックアップではなく、Paceの通常の復元画面へ入れない。対応する復旧作業が必要。ブラウザの保存データを消す操作は、復旧に必要なファイルの確保と確認が終わるまで行わない。
