# Pace 2.2.0 更新・確認手順

既存の2.1.1を保護した複製で開発しました。金融データ、既存の認証、IndexedDBの削除を伴う操作は行っていません。公開先の更新は別の作業です。

## 更新前

1. 現行アプリで暗号化バックアップを作り、保管庫とバックアップのパスフレーズを確認します。
2. 初めに架空データの検証用環境へ配置します。既存と同じHTTPSオリジン・パス・PWA scopeを維持します。別のドメインやscopeでは、同じIndexedDBを読めません。
3. Node 22.12以上で npm ci、npm test、npm run build、npm run privacy:audit を実行します。テスト対象は架空データだけです。
4. distの全ファイルを静的配信します。ocrのworker、WASMラッパー、jpn/eng traineddata.gzも必要です。別サイトのOCRやCDNへ置き換えないでください。

## データと戻し方

- IndexedDBのバージョンは3のままです。追加フィールドは任意で、既存の全ストア・暗号化・鍵を維持します。DBを削除して更新しないでください。
- 新しいバックアップのschemaは3です。1・2・3を読み込めます。2.1.1はschema3のバックアップを復元できません。旧版へ戻す可能性がある場合、更新前のバックアップも残してください。
- 2.1.1→2.2.0の実際のService Worker更新で、暗号化した各テーブルを復号比較しました。DBバージョン・内容を維持し、オフライン再起動と入力にも成功しています。
- 古いOCRコード専用Cacheだけを更新時に整理します。IndexedDB・ユーザー記録は消しません。
- 入力画面を閉じてからPWAの更新を適用します。端末のサイトデータ削除やアプリ削除は更新手順に含めません。

## 端末内処理と制約

- OCRはTesseract.js 7、初めて使うときだけ同じ配信元の静的ファイルを取得します。画像をアップロードしません。通常起動時はOCRファイルを読み込みません。
- OCRファイルを取得する前の完全オフライン環境では読み取れません。手入力が使えます。初回読取後のオフラインOCRはiPhoneでも別途確認してください。
- 写真は20MB・24MP以下のJPEG/PNG/WebP。サイズを復号前に確認し、1800pxに縮小、確定したレシート領域を最大1600pxに補正します。HEICはJPEGに変換するか撮影し直してください。
- 検出は白い紙の領域を使う控えめな補助です。常に四隅と背景除去の確認が必要です。薄い紙・白背景・折れ・反射・複雑な背景では手動調整してください。
- 撮影ガイドはライブ表示、品質判定は撮影後です。連続フレームの品質判定・自動撮影・任意角度の自動回転検出は実装していません。
- 金額候補は確認を補助するスコアで、正解確率の保証ではありません。複数の合計候補は再OCRでも低い確かさのまま表示します。
- 重いAIモデル・WebGPU・クラウドLLMは導入していません。カテゴリー・検索・候補順位・傾向はルールと既存履歴で動きます。
- 9種類の通知は端末内で実際の条件を評価します。アプリを閉じた状態での時刻通知を保証するバックグラウンドスケジューラやPush配信サーバーはありません。
- OS通知は金額なし。金額表示の設定はアプリ内だけに適用します。カレンダーの汎用通知はカレンダー側でQuiet Hours・変更・削除を管理します。

## 実機リリース確認

まず架空データを使って、ホーム画面に追加したiPhone PWAで以下を確認してください。

1. 375/390/430px相当の端末、iPad、ライト/ダーク、テーマ、Safe Area、文字サイズ拡大。
2. 金額入力・キーボード・5〜10秒での通常記録・全支払元・Apple Payと実Accountの区別。
3. 日本語の架空レシート、背景の文字、斜め、長い紙、ブレ、暗さ、反射、画像回転、四隅ドラッグ。
4. 初回/再読取の時間とメモリ、読取中の中止、画面を隠す操作、低メモリ、オフライン、カメラ権限拒否。
5. 画像保存OFFで保存されないこと、ON時の添付、Undo、暗号化バックアップと復元。
6. 残高を一括確認した後の数字、マイナスの使える金額、未確認残高、入力中の別タブ変更。
7. iPhone PWAの通知許可、汎用ロック画面表示、Quiet Hours、スヌーズ、確認済み、閉じた状態の制約。
8. 最適化OFF・カード固定、旧版からの更新、オフライン再起動、PIN/パスキー/保管庫の解除。

この実機確認が完了するまで、検証済みの本番候補という位置づけです。本番利用可能とはまだ判定していません。

## ブラウザー検証の再実行

`npm run test:experience` と `npm run test:exports` はPlaywrightのChromiumを使用します。インストール済みChromeを使う場合、PowerShellで次を設定できます。すべて一時的な架空プロフィールで実行します。

```powershell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE = "C:/Program Files/Google/Chrome/Application/chrome.exe"
npm run test:experience
npm run test:exports
```

更新保持試験には、保管した旧2.1.1のビルドも必要です。通常の開発・利用には不要です。

```powershell
$env:PACE_QA_PREVIOUS_DIST = "C:/検証/pace-2.1.1/dist"
npm run build
npm run test:preservation
```

ソースZIPにはソース、静的OCRファイル、架空データの検証記録を含め、node_modulesとdistは含めていません。配信用ZIPにはビルド済みdistの全内容を含めています。
